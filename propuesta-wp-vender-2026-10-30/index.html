⚙️ DEVELOPER LOGIC RULES (DO NOT RENDER THIS TEXT IN THE UI / REGLAS DE LÓGICA - NO MOSTRAR ESTE TEXTO EN LA WEB):

Estado inicial: los dos checkbox nuevos («Precios diferentes» y «Extras del evento») nacen apagados al crear un evento. Aquí están encendidos para que se vean las filas. Cada fila de precio es un importe propio, no un recargo sobre la entrada base. Entrada 10 € y pack familiar 25 €: 1 pack = 25 €, no 35 €. Los extras se suman. Total = Sum(entradas elegidas * precio) + Sum(extras elegidos * precio). El extra es lo que lleva la comisión. Cada unidad de entrada resta 1 de «Entradas disponibles» (por ejemplo 40). Los extras no restan entradas. IF el campo nativo «URL externa» está activo o relleno: se mantiene el salto a la web del organizador y NO se pinta la caja de compra nueva. IF el precio de la entrada es 0 Y «Precios diferentes» está apagado: el evento es gratis. No añadas un interruptor aparte de gratuito.

Default state: Both new checkboxes ("Different prices" and "Event extras") are OFF by default when creating an event. They are ON here so the rows are visible. Independent Ticket Types: Each price row is an independent ticket price, NOT a surcharge on top of the base ticket (e.g., Base Ticket = 10 €, Family Pack = 25 €. Picking 1 Family Pack = 25 €, NOT 35 €). Event Extras: Extras ADD to the total (Total = Sum(Selected_Tickets * Price) + Sum(Selected_Extras * Price)). Extras carry the platform commission. Stock / Capacity Deduction: Every ticket unit selected deducts 1 from the native Available tickets field (e.g. 40). Extras DO NOT deduct from available tickets. External URL Override (CRITICAL): IF native "External URL" field is active/filled -> Keep current external redirect behavior and DO NOT render the new Purchase Box. Free Events: IF Ticket Price == 0 AND "Different prices" is OFF -> Event is Free (do not add a separate "Free" toggle).
